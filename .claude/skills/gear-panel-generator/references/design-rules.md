# Design rules (approved; follow strictly)

**Accuracy** — Trace, don't invent: layout, order, which side jacks/switches sit, label wording, knob style come from photo+manual (JCM800: inputs on the right, knobs Presence→Pre-amp left→right). User list conflicts with real panel → follow panel, flag it. Show only controls captures record: omit power/standby, FX loop, rear panel, unused second EQ. Inputs ≠ channels: input jacks are selectable jack buttons with visible plugged-in state (`.jjack`, "● Plugged in / ○ Empty"), not lever switches. Single-channel: no tabs/selector; the stage already shows a "Recorded … channel" pill — don't add another.

**Visual** — Flat vector look: no gradients/reflections/shine/simulated metal; flat fills, thin outlines, real panel colours. (Existing `.cab`/grille textures are legacy; don't copy gradients into new panels.) Knobs match real shape (smooth vs fluted, colour, printed scale/numbers); pointer rotates −150°→+150° across min→max; amber `.ro`/`.jro` readout on every knob. Lever switches: draw them with the shared `Lever` primitive (`<Lever pos horizontal?>`, or `<Toggle>` with its position labels): a recessed rounded slot (dark fill, light rim) with the silver lever tip at the chosen end or in the middle, and a short shaft leaning to it; vertical 22×32 or horizontal 32×20 to match the gear. Position labels are small text buttons. Pull pots: label toggle with dot filled when on (`PickButton` with `.pdot`) + thin ring on the knob (`.knobbox.pulled`). Cabinet: black tolex `width:fit-content;max-width:100%`, spacing outside; grille ≈60–70px; faceplate tight padding, no big gaps. Model name as plain text; never a logo, script wordmark or signature.

**Behaviour** — Wrap at narrow widths; no horizontal scroll at 390px. Real `<button>`s with `aria-pressed` and descriptive `aria-label`; hidden range inputs with `aria-valuetext` (the primitives in `src/ui/primitives` provide both); visible focus rings (recolour on light panels: `.jface .knob-in:focus-visible + .kwrap{outline-color:#111}`); touch targets ≥40–44px; colour never the only signal. Copy: "closest match", "settings similarity", the visual-reference note. No synthetic data.
